# Welcome to QuanRobotics

QuanRobotics is building an open and extensible software operating layer for the Physical AI ecosystem.

Our goal is to connect:

- Robot and sensor interfaces
- Simulation and digital twins
- Robot and perception data
- Perception and edge intelligence
- Policy and world-model evaluation
- Developer workflows and deployment

## Platform Direction

- **QR-Core**: SDKs, schemas, configuration and shared developer workflows
- **QR-Sim**: Simulation, scenarios, digital twins and synthetic data
- **QR-Perception**: Perception pipelines and edge deployment
- **QR-RobotData**: Dataset conversion, validation and quality
- **QR-WorldBench**: Evaluation, benchmarking and failure analysis

August 2026 is our foundation stage. Public repositories will be released progressively after meeting documentation, testing, security and reproducibility standards.

Follow this organization for contributor-ready issues, technical documentation and upcoming releases.

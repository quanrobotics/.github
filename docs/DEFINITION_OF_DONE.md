# QuanRobotics Definition of Done

A task or pull request is considered complete only when:

- [ ] An approved issue exists.
- [ ] Acceptance criteria are satisfied.
- [ ] Required implementation is complete.
- [ ] Required tests pass.
- [ ] CI checks are green.
- [ ] Required reviewer approvals are complete.
- [ ] Required CODEOWNER approval is complete.
- [ ] Review conversations are resolved.
- [ ] Security implications are reviewed.
- [ ] Dependency implications are reviewed.
- [ ] Documentation is updated.
- [ ] Reproduction instructions are available.
- [ ] Known limitations are documented.
- [ ] Required evidence is linked.
- [ ] No credentials or confidential information are exposed.
